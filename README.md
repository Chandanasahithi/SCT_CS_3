# SCT_CS_3 - Secure Password Generator

## Description
This project is a Secure Password Generator developed using Python.  
The application generates strong and random passwords using uppercase letters, lowercase letters, numbers, and special characters to improve password security.

## Features
- Generates secure random passwords
- User-defined password length
- Includes:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special characters
- Strong password generation logic
- Beginner-friendly interface

## Technologies Used
- Python
- Google Colab

## How It Works
1. User enters desired password length
2. Program combines multiple character sets
3. Random secure password is generated
4. Password is displayed instantly

## Example Output
Enter desired password length: 12

Generated Secure Password:
A#7kLp!2Qx@9

Password generated successfully!
